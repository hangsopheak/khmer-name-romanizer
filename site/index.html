    Pre-fill a form

    For enrolment, HR onboarding and registration forms. The Latin field fills itself while the person types in Khmer. They pick or correct the spelling, then confirm.

    Student enrolmentExample form

    How it works

    • The first suggestion goes into the Latin field until the person edits it.
    • The other spellings appear as buttons, so a person whose ID says Boppha can pick it with one tap.
    • The form asks for confirmation. The library suggests a spelling. The person decides.
    import { createDefaultTransliterator } from 'khmer-name-romanizer'
const t = createDefaultTransliterator()

khmerInput.oninput = () => {
  const { value, candidates } = t.transliterate(khmerInput.value)
  if (!latinInput.dataset.edited) latinInput.value = value
  showSuggestions(candidates)   // buttons the person can tap
}

    Check a typed name

    For KYC, exams and diplomas. Compare the Latin name someone typed with the Khmer name on their National ID. A match passes. Anything else goes to a person, not straight to a rejection.

    Try:

    How it works

    The check looks for the typed name among the ranked spellings, in either name order. The score tells you how common that spelling is: 0 is the usual spelling, and far below 0 means a real but uncommon one.

    const t = createDefaultTransliterator({
  flipOrderCandidates: true,   // "Sophea Chhim" also matches
  maxCandidates: 10,
})
const norm = (s) => s.toLowerCase().replace(/[^a-z]+/g, ' ').trim()

function check(khmer, latin) {
  const hit = t.transliterate(khmer).scoredCandidates
    ?.find((c) => norm(c.value) === norm(latin))
  return hit ? hit.score : null   // null → send to review
}

    Audit records

    For data-quality work on any database that stores both scripts. Find the rows where the Latin name does not fit the Khmer name: typos, rare spellings to confirm, and rows that belong to a different person.

    Audit your own records

    One record per line: Khmer name, a comma, then the Latin name. Your data stays in this browser.

    How it works

    • Matches The Latin name is one of the known spellings.
    • Rare spelling Valid, but uncommon. Confirm it with the person.
    • Likely typo One letter away from a known spelling.
    • Mismatch Does not fit the Khmer name. It may be the wrong person.
    for (const row of records) {
  const score = check(row.khmer, row.latin)  // see "Check a typed name"
  if (score === null) flag(row, 'mismatch')
  else if (score < -3) flag(row, 'rare')
}

    This demo also counts how many letters a mismatch is away from the nearest spelling. One letter off is treated as a typo.

    Link records

    For dedup and record linkage. One system stores a person in Khmer, another in Latin, written by different clerks in different ways. Find the Latin records that belong to the same person.

      How it works

      • Same person: the Latin record equals one of the spellings, in either name order.
      • Possible: one letter away from a spelling, probably a typo. A person should look.
      • Different: further away than that, so most likely another person.

          How it works

          Build a search index once: for each Khmer record, store every spelling of every word. Then match what staff type against those spellings.

          const index = contacts.map((c) => {
  const r = t.transliterate(c.khmerName)
  const words = r.tokens.flatMap((w) => [w.latin, ...w.alternatives])
  return { contact: c, words: words.map(norm) }
})

const find = (q) => index.filter((e) =>
  e.words.some((w) => w.startsWith(norm(q))))

          Convert a list

          For migrations and display. Give Latin names to records that only have Khmer, for a new system, an SMS without Khmer fonts, or staff who do not read Khmer. Uncertain rows go to a review queue.

          KhmerLatinConfidence

          How it works

          • High Every word is a known name word and one spelling clearly leads.
          • Check Known words, but other spellings are also common.
          • Review At least one word is new and was read by rules only.

  const r = t.transliterate(row.khmerName)
  row.latinName = r.value
  if (r.source === 'rules') reviewQueue.push(row)

          It suggests. You decide.

          Only the person knows how their name is officially spelled. Use the results to pre-fill a form or to flag a mismatch, and let a person confirm before anything goes on an ID, diploma or registry record.

          How accurate is it?

          Name in the dictionary, first guess right83–97%
          New name, first guess right~30%
          New name, correct spelling in top 5~43%

          Most misses are close, such as Penn Rorn for Pan Ron. Every reported spelling makes it better.

          Private by design

          Names are personal data. The whole engine and dictionary load into this page, and nothing is sent to a server. The same is true in your app: no API key, no network calls, no dependencies.
